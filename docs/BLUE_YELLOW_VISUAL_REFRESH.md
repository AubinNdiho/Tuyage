# Tuyage — Blue & Yellow visual refresh

Base: Tuyage OPUS v3.0.15 DOUBLE_CLIC_FIX.

Changes intentionally limited to visual identity:
- original Tuyage layout and Java UI structure preserved;
- original functionality and gRPC/protobuf code preserved;
- Aero-inspired blue/yellow/cream palette applied to the existing Tuyage CSS;
- selected new Tuyage blue/yellow conversation logo installed as `images/logo.png`;
- dark mode accents aligned to blue/yellow.

No RPC, database, call engine, authentication flow or navigation structure was changed by this refresh.
