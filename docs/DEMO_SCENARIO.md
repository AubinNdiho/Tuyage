# Scénario de démonstration – Tuyage 3.0 FINAL TP

1. **Serveur** : lancer `run-server.bat`, montrer `LISTENING` sur 9090.
2. **Deux clients** : PC A et PC B utilisent `IP_SERVEUR:9090`.
3. Créer deux comptes par numéro de téléphone et montrer la carte **Moi**.
4. Ajouter l'autre numéro dans **Contacts**.
5. Envoyer un texte : notification, badge, `✓`, `✓✓`, puis `✓✓` bleu après lecture.
6. Répondre, modifier, réagir, épingler, transférer puis rechercher un message.
7. Enregistrer un vocal : clic micro -> compteur -> **Entrée = envoi immédiat**.
8. Envoyer image/vidéo/fichier puis ouvrir **Médias, liens et fichiers**.
9. Créer un groupe, nommer un admin, retirer/ajouter un membre.
10. Publier un statut texte puis image/vidéo, l'ouvrir depuis l'autre compte, afficher les vues et répondre.
11. Appel audio : tonalité appelant + sonnerie entrante personnalisée + historique persistant.
12. Appel vidéo : correspondant en grand, soi en vignette, caméra/micro on/off.
13. Appel de groupe : chaque membre choisit **Rejoindre / Ignorer** ; seuls les participants reçoivent le média.
14. Mettre une conversation en sourdine, l'épingler et l'archiver puis la restaurer.
15. Bloquer un contact : plus de messages/appels/statuts/presence détaillée ; puis débloquer.
16. Fermer brutalement un client : après quelques secondes l'autre le voit hors ligne ; relancer pour démontrer la reconnexion.
17. Tester **Mot de passe oublié ?** avec l'OTP de démonstration.
18. Fermer/reouvrir : données et historique restent dans H2.
